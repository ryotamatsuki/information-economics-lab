## Reproduction
Run individual scripts with Python and the dependencies in `requirements.txt`; original outputs are retained next to the source. Scripts are standalone diagnostics, not a packaged tested library. No rerun was performed during archiving. The original logs document calculation results, not independent human peer review or formal proof certification.
